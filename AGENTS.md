# Project conventions

- Write project documents as technical specifications and factual reports: purpose, settings, evidence, results, and unresolved issues.
- Do not include conversation quotations, personal speaking styles, or permission and approval histories in project files.
- Preserve original research data, third-party sources, and hashed experimental snapshots. Record implementation supplements and validation scope explicitly.
- Keep research source files under `/data2/radiology_datas/clean3/` read-only. Store code and small outputs here; store large generated assets under `/data5/take/brainode`.
